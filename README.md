# sortAlgorithm

アルゴリズムとデータ構造 レポート No.5 の自由課題。ソートアルゴリズムの可視化。

1〜200 をランダムに並べた配列に対して 7 種類のソートを同時に実行し、配列の変化を棒グラフのアニメーションで表示する Web アプリ。

## 対象のソート

| ソート | 補足 |
|---|---|
| バブルソート（通常版） | 打ち切りなし |
| バブルソート（改良版） | 1 周の間に交換がなければ終了 |
| 選択ソート | |
| 挿入ソート | |
| マージソート | |
| クイックソート | ピボットは中央要素 `A[(left + right) / 2]` |
| ヒープソート | |

## 機能

- ページを開くと 7 種類のソートが同時に動き出す（4 列 × 2 行で 1 画面に表示）
- 横軸は配列番号、棒の高さは値。比較・交換中の要素は赤、整列が終わると緑で表示
- 各グラフの下に、その時点の **比較回数**・**交換・代入回数**・進捗を表示
- 全ソートが終わると再生バーを動かせるようになり、好きな位置から再生し直せる
- 再生速度は 200〜20,000 ステップ/秒 の 6 段階で切り替えられる

### 時間軸について

1 ステップ = 比較 1 回 または 交換・代入 1 回 とし、全ソートを同じ速さで進めている。そのため、手数の多い O(n²) のソート（バブル・選択・挿入）は遅く、O(n log n) のソート（マージ・クイック・ヒープ）は早く終わる様子がそのまま見える。

### 回数の数え方

課題 2 の測定と同じ数え方にしている。

- 比較：配列要素を 1 回比較するたびに 1 回
- 交換：`swap` 1 回を 1 回と数える
- 挿入ソート：ずらし（`A[j+1] = A[j]`）を 1 回と数える。退避（`v = A[i]`）と書き戻し（`A[j+1] = v`）は数えない
- マージソート：一時配列への退避と書き戻しを、どちらも 1 回と数える

## 実行方法

Node.js（v20.19 以上、または v22.12 以上）が必要。

```bash
cd visualizer
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開く。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型チェックと本番用ビルド（`dist/` に出力） |
| `npm run preview` | ビルド結果を確認 |
| `npm run lint` | oxlint によるコードチェック |

## 仕組み

1. **記録**：ページを開いたときに各ソートを最後まで実行し、比較・交換・代入の操作を順番にすべて記録する（`algorithms/`）
2. **再生**：記録した操作を初期配列に 1 つずつ適用して、指定したステップ時点の配列と回数を再現する（`player/TracePlayer.ts`）。一定間隔で配列の状態を保存しておき、巻き戻しのときはそこから再生し直すことで、再生バーを動かしても重くならないようにしている
3. **描画**：200 本 × 7 個の棒を毎フレーム描き直すため、DOM 要素ではなく canvas で描画している（`utils/drawBars.ts`）

```
└── constants/colors.ts          棒グラフの色
```
